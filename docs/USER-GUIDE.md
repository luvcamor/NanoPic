# NanoPic 3.0 用户说明

NanoPic 3.0 是 Windows 10/11 x64 的图像压缩与转换工具。发布目录中的 `NanoPic.exe` 是**单个便携可执行文件**，依赖系统的 .NET Framework 4.8 与 Windows Imaging Component，不需要安装 .NET 8 Desktop Runtime。发布目录同时保留许可证、SBOM、哈希和 manifest 等审计材料；它们不是运行依赖。

| 项目 | 位置或说明 |
|---|---|
| 主程序 | `artifacts/publish/win-x64/NanoPic.exe` |
| SHA-256 校验 | `artifacts/publish/win-x64/NanoPic.exe.sha256` |
| 第三方声明 | `artifacts/publish/win-x64/THIRD-PARTY-NOTICES.txt` 与 `licenses/` |
| 组件清单 | `artifacts/publish/win-x64/SBOM.spdx.json` |
| 发布清单 | `artifacts/publish/win-x64/manifest.json` |
| 用户设置 | `%LOCALAPPDATA%\NanoPic\settings.json` |

## 启动与导入

双击 `NanoPic.exe` 即可启动。可以通过“添加文件”、文件夹导入或把文件拖入文件队列来加入任务。支持的输入与输出格式为 JPEG、PNG、WebP、GIF、BMP、TIFF 和 ICO；程序先按文件内容签名识别格式，**不会仅凭文件扩展名决定编解码器**。

文件夹导入会跳过不受支持的文件与 reparse point，并隔离单个文件的读取错误，使坏文件不会阻止其余文件处理。队列可用于单文件、多个文件或文件夹批处理。

## 输出与命名

输出设置支持源目录、独立输出目录以及保留目录结构。命名方式为下拉预设：**保持原文件名**（默认）、原文件名 + 序号、仅序号、日期时间（取文件的修改时间，例如 `2024-05-06_07-08-09.jpg`），以及自定义。自定义模板支持占位符：`{name}` 原文件名、`{index}` 序号、`{ext}` 输出格式、`{date}` 日期、`{time}` 时间。起始序号和重复输出策略均可设置：**覆盖**（默认，调整设置后重新压缩直接替换上次结果）、自动重命名、跳过或报错。若输出目录中存在需要保护的同名文件，可切换为自动重命名以避免被替换。

“覆盖原文件”模式：输出格式与原格式相同时直接替换原文件；发生格式转换时（例如 PNG 转 JPEG），会在原文件所在目录生成新扩展名的结果文件，并**保留原文件**，避免格式转换过程中丢失原图。

“原格式”输出会保留由输入文件签名识别出的实际格式，而不是猜测扩展名。每次写出后，程序会重新读取结果以验证签名和尺寸；无效或未写出的文件不会报告为成功。

## 压缩与图像处理

可以选择目标格式与质量，或按目标文件大小压缩。
- **质量模式**：JPEG 与 WebP 调节编码器质量；PNG 质量代表颜色量化优化强度（100 为完全无损，数值越低通常文件越小，且默认保持图片宽高不变）；GIF/BMP/TIFF/ICO 不支持质量调节。
- **目标大小模式**：优先在保持图片原始宽高（Width × Height）的前提下搜索最佳视觉质量；若原尺寸无法达到目标大小：
  - 默认情况下不会擅自缩小图片分辨率；
  - 勾选「无法达到目标时允许缩小图片尺寸」后，系统才会在原尺寸无法满足时自动等比缩小分辨率以逼近目标大小；
  - 若不可达且不允许超限/缩放，会返回明确的不可达状态，不会损坏原图或生成半成品。
- **超限自动降采样**：仅在图片像素总数超过安全上限时自动缩小以防止内存溢出，与按目标大小的尺寸调整互不影响、独立工作。

| 设置 | 作用 |
|---|---|
| 质量 / 目标大小 | 控制 JPEG/WebP/PNG 的优化强度或目标字节上限。 |
| 允许缩小尺寸 | 仅在按目标大小且原尺寸无法达到时，允许进一步降低图片分辨率。 |
| 缩放 | 主动修改宽高，可保持或忽略原始宽高比。 |
| 亮度 | 对图像像素应用亮度倍率。 |
| 文字水印 | 设置文字、颜色、不透明度、字号和边距。 |
| 透明背景填充 | 输出到不支持透明度的格式时，可先用指定颜色扁平化透明区域。 |
| 自动摆正照片方向 | 手机竖拍等带方向标记的照片自动转正后再处理，避免输出后在部分软件里躺倒显示。 |
| 元数据策略 | 可保留或清除元数据；方向修正会依据照片的拍摄方向信息完成。 |
| GPU 入口 | 保留 GPU/CUDA 设置入口；当加速不可用时自动采用可靠的 CPU 后端。 |

动画 GIF 在选择 GIF 输出时按多帧集合处理并保留多帧。选择其他输出格式时的动画策略取决于该目标格式的能力；请在批量转换前先用一份样本确认结果。

## 任务进度、取消与恢复

开始压缩后，任务区域显示进度。可使用取消入口请求停止：已安全完成的项目保留，尚未完成的项目得到结构化取消结果，程序不会把未完整写出的文件当成成功。失败项目可以从队列重新尝试；处理日志用于查看脱敏的状态与原因；“打开输出目录”可直接定位生成结果。

### 队列操作与快捷键

队列行高亮用于预览和右键操作，复选框用于决定是否参与处理。右键菜单支持预览、打开所在文件夹、勾选/取消勾选高亮项、重试失败项和移除高亮项。

| 快捷键 | 操作 |
|---|---|
| `Ctrl+O` | 添加图片文件 |
| `Ctrl+Shift+O` | 添加图片文件夹 |
| `Ctrl+A` | 勾选全部队列项 |
| `Ctrl+I` | 反转勾选状态 |
| `Enter` | 预览高亮图片 |
| `Delete` | 移除高亮项 |
| `F5` | 开始处理已勾选文件 |
| `Esc` | 取消当前批次 |

默认窗口为 950×600、最小窗口为 820×540，并默认居中；已完成核心取消语义、快捷键路由测试、辅助名称枚举和紧凑布局边界验证。最终 net48 单 EXE 已在可见前台验证文件对话框导入、Explorer 拖放、`F5` 开始、运行中 `Esc` 取消、队列右键菜单、`Enter` 预览和失败项右键重试；300 MB 高熵输入取消后显示“已取消 / 取消 1”，且没有留下完整输出。150%/200% 自动化布局已通过；物理显示器 DPI 切换按用户决定跳过。

## 设置迁移与隐私

旧版设置可迁移到 `%LOCALAPPDATA%\NanoPic\settings.json`。新设置不会写入 EXE 所在目录，保存采用同目录临时文件、原子替换与 `.bak` 备份；损坏配置不会被静默删除。默认日志会脱敏绝对路径和异常细节，详细信息仅在需要排障时查看。

## 盲水印状态

旧版源码中的盲水印入口本身未实现。新版会明确标记该能力为 `LEGACY_UNIMPLEMENTED`，不会宣称它已经可用。
