# NanoPic 使用说明

NanoPic 是一款适用于 Windows 的便携图片压缩与格式转换工具。程序只有一个主文件，无需安装；图片全程在本地处理，不会上传到网络。

## 下载与启动

1. 打开 [NanoPic Releases](https://github.com/luvcamor/NanoPic/releases/latest)。
2. 直接下载 `NanoPic.exe`，或下载名称中带有 `win-x64` 的便携压缩包并解压。
3. 双击 `NanoPic.exe` 启动。

运行环境：Windows 7 或更高版本、64 位系统、.NET Framework 4.8。大多数较新的 Windows 系统已经包含所需运行环境。

如果 Windows 显示安全提示，请先确认文件来自本仓库的正式 Release 页面，并核对发布页提供的 SHA-256 校验值。

## 添加图片

你可以通过以下方式添加待处理图片：

- 点击“添加文件”选择一张或多张图片；
- 点击“打开文件夹”批量导入文件夹中的图片；
- 将图片直接拖入 NanoPic 窗口。

支持 JPG、PNG、WebP、GIF、BMP、TIFF 和 ICO。遇到损坏或不支持的文件时，NanoPic 会跳过该文件并显示原因，不会中断整个批次。

## 快速开始

1. 添加图片。
2. 选择输出格式。
3. 按需要设置质量或目标文件大小。
4. 确认输出目录和文件命名方式。
5. 点击“开始压缩”或按 `F5`。

处理完成后，可以通过“打开输出目录”查看结果。

## 压缩设置

### 按质量压缩

- JPEG 和 WebP：数值越高，通常画质越好、文件越大。
- PNG：质量 100 表示无损；降低质量会减少颜色数量，在保持宽高不变的前提下进一步减小体积。
- GIF、BMP、TIFF 和 ICO 不提供质量调节。

对于已经优化得很小的 PNG，如果重新编码不能减小体积，NanoPic 会保留原图数据，避免越压越大。

### 按目标大小压缩

NanoPic 会优先保持图片原始宽高，并自动寻找尽可能高的可用质量。

如果原尺寸无法达到目标大小：

- 默认会明确提示目标不可达，不会擅自降低分辨率；
- 开启“无法达到目标时允许缩小图片尺寸”后，NanoPic 才会等比缩小图片继续尝试；
- 已经小于目标大小的 PNG 会直接保留，不进行没有必要的重复压缩。

目标大小是尽量逼近的上限。图片内容、格式和透明度都会影响最终体积。

## 图像处理

NanoPic 还支持以下常用处理：

- 调整图片宽高，可选择保持原始比例；
- 自动摆正手机照片方向；
- 调整亮度；
- 添加文字水印并设置位置、颜色、字号和透明度；
- 输出到不支持透明度的格式时，用指定颜色填充透明区域；
- 按需保留或清除图片元数据。

建议在批量处理重要图片前，先用一两张样图确认效果。

## 输出位置与文件名

输出可以保存到原文件夹、独立文件夹，或在独立文件夹中保留原有目录结构。

文件名支持以下方式：

- 保持原文件名；
- 原文件名加序号；
- 仅使用序号；
- 使用日期和时间；
- 使用自定义模板。

自定义模板可使用：`{name}` 原文件名、`{index}` 序号、`{ext}` 输出扩展名、`{date}` 日期、`{time}` 时间。

遇到同名文件时，可以选择覆盖、自动重命名、跳过或报错。如果输出目录中已有需要保留的文件，建议选择“自动重命名”。

选择“覆盖原文件”时，请确认原图已经备份。格式转换会生成对应的新扩展名文件；例如 PNG 转 JPEG 时，原 PNG 会保留。

## 队列与快捷键

| 快捷键 | 操作 |
|---|---|
| `Ctrl+O` | 添加图片文件 |
| `Ctrl+Shift+O` | 添加图片文件夹 |
| `Ctrl+A` | 勾选全部队列项 |
| `Ctrl+I` | 反转勾选状态 |
| `Enter` | 预览当前图片 |
| `Delete` | 从队列移除当前项目 |
| `F5` | 开始处理已勾选项目 |
| `Esc` | 取消当前批次 |

取消任务时，已经完整处理的文件会保留；尚未完成的文件不会被当作成功结果。

## 设置与隐私

NanoPic 的设置保存在 `%LOCALAPPDATA%\NanoPic\settings.json`。删除 NanoPic.exe 不会自动删除该设置文件，如需彻底清理，可以手动删除对应文件夹。

所有图片处理都在本地完成。默认日志不会公开你的完整文件路径；只有在排查问题时才需要查看详细信息。

## 常见问题

### 为什么压缩后的图片没有明显变小？

源文件可能已经压缩得很好，或者当前质量设置较高。可以适当降低质量，或使用目标大小模式。NanoPic 不会为了追求更小体积而自动破坏原图尺寸，除非你主动允许缩小分辨率。

### 为什么目标大小无法达到？

部分图片即使降低质量也有格式本身的体积下限。可以开启“允许缩小图片尺寸”，或者改用 JPEG/WebP 等更适合照片的格式。

### 为什么 PNG 的颜色看起来有变化？

PNG 质量低于 100 时会进行颜色量化。需要完全保留原始颜色时，请使用质量 100。

### 程序打不开怎么办？

确认系统为 64 位 Windows，并已启用 .NET Framework 4.8。仍无法启动时，请在 [GitHub Issues](https://github.com/luvcamor/NanoPic/issues) 中说明 Windows 版本、操作步骤和错误提示。

## 问题反馈

如果遇到异常，请前往 [GitHub Issues](https://github.com/luvcamor/NanoPic/issues) 提交问题。建议附上：

- NanoPic 版本；
- Windows 版本；
- 输入和输出格式；
- 能够复现问题的操作步骤；
- 界面显示的错误提示。

请不要上传包含隐私信息的原始图片；如需提供样图，可以先进行裁剪或脱敏。
